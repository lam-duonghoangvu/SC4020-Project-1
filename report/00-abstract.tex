\begin{abstract}
\noindent
Clustering is used when there are no labels to check the result against, so a clustering is usually
judged by an internal score such as the silhouette. We test whether that is safe. The methods assume
different things: K-means expects compact groups, while DBSCAN and HDBSCAN expect dense groups separated
by empty space. We ran K-means (with random and K-means++ starts), DBSCAN and HDBSCAN
on eight datasets chosen to break these assumptions. Six of the datasets have known labels. We asked
three questions: does a method fail when its assumption breaks, can the failure be seen without labels,
and does a known remedy fix it? Every method failed where its assumption broke. K-means cut two curved
clusters in the wrong place (agreement with the true labels 0.48 out of 1, against 0.98 for DBSCAN), and
on housing data with no empty space between groups both density methods put most points in one cluster.
The silhouette did not reveal these failures: on five of the six labelled datasets it favoured a
different method from the one that best matched the labels. Comparing each result with the same method
run on shuffled data caught results with no real structure, but not K-means joining earthquake belts
thousands of kilometres apart into one cluster. Remedies such as measuring distance on the sphere and
using HDBSCAN fixed the failures they target, but none helped data with no gaps. No single score can
choose a clustering method: an analyst should look at the data, report how many points each method
discards, and test directly for the failures the data make likely.
\end{abstract}
