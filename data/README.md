# Data

CSV files in this folder are not committed to the repo (too large / redistributable). The
`wine` and `make_moons` datasets are generated directly via scikit-learn and need no download.

Download the remaining two datasets and place the files directly in this folder:

## Mall Customers

- Source: [Customer Segmentation Tutorial in Python](https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python) (Kaggle)
- File needed: `Mall_Customers.csv`

## Fashion MNIST

- Source: [Fashion MNIST](https://www.kaggle.com/datasets/zalando-research/fashionmnist) (Kaggle)
- Files needed: `fashion-mnist_train.csv`, `fashion-mnist_test.csv`

data/
