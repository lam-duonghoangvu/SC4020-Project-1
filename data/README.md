# Data

There are three ways a dataset arrives:

- **Built into scikit-learn**: shipped with the `scikit-learn` package or generated by it. Nothing
  to download.
- **Downloaded automatically**: the loader fetches the file on first use (into this folder, or into
  the kagglehub cache). Nothing to do beyond having internet access the first time.
- **Placed by hand**: the loader reads a file from this folder and fails if it is missing. Run the
  command in the table once.

All commands run from the repo root.

## Built into scikit-learn

No download and no files. Wine, Breast Cancer Wisconsin and Digits are copies of the UCI tables
that ship inside the `scikit-learn` package; make_moons and the varied-density blobs are generated
with a fixed seed. To check they load:

```python
from sklearn.datasets import load_wine, load_breast_cancer, load_digits, make_moons, make_blobs

load_wine()           # 178 x 13, 3 cultivars
load_breast_cancer()  # 569 x 30, benign / malignant
load_digits()         # 1,797 x 64, 10 digits
make_moons(n_samples=1000, noise=0.07, random_state=42)
```

## Kaggle datasets

Wine, Breast Cancer, Uber, Mall Customers and Fashion-MNIST come from Kaggle. Downloading needs a
Kaggle account and an API token (`~/.kaggle/kaggle.json`, or the `KAGGLE_USERNAME` and
`KAGGLE_KEY` environment variables).

`sc4020.hoanganh` and the team comparison fetch them through `kagglehub`, which keeps them in its
own cache (`~/.cache/kagglehub/`), so nothing goes in this folder.

`sc4020.lam` (Mall Customers, Fashion-MNIST) and `sc4020.ky` (Uber) read files from this folder.
Download them once with kagglehub and copy the files here:

```bash
uv run python - <<'EOF'
import glob, os, shutil, kagglehub

for slug, files in {
    "vjchoudhary7/customer-segmentation-tutorial-in-python": ["Mall_Customers.csv"],
    "zalando-research/fashionmnist": ["fashion-mnist_train.csv", "fashion-mnist_test.csv"],
    "fivethirtyeight/uber-pickups-in-new-york-city": ["uber-raw-data-apr14.csv"],
}.items():
    folder = kagglehub.dataset_download(slug)
    for name in files:
        src = next(p for p in glob.glob(os.path.join(folder, "**", "*"), recursive=True)
                   if os.path.basename(p) == name)
        shutil.copy(src, os.path.join("data", name))
        print("data/" + name)
EOF
```

Or with the Kaggle CLI (`pip install kaggle`):

```bash
kaggle datasets download -d vjchoudhary7/customer-segmentation-tutorial-in-python -p data --unzip
kaggle datasets download -d zalando-research/fashionmnist -p data --unzip
kaggle datasets download -d fivethirtyeight/uber-pickups-in-new-york-city -f uber-raw-data-apr14.csv -p data --unzip
```

The Fashion-MNIST archive also holds the raw `*-ubyte` files; only the two CSVs are used.

## Earthquakes 1965-2016 and Ecoli

Plain files on GitHub, no account needed. The team comparison downloads both on first use;
`sc4020.ky` needs them placed by hand:

```bash
curl -o data/earthquakes.csv https://raw.githubusercontent.com/plotly/datasets/master/earthquakes-23k.csv
curl -o data/ecoli.arff https://raw.githubusercontent.com/deric/clustering-benchmark/master/src/main/resources/datasets/real-world/ecoli.arff
```

`earthquakes.csv` has 23,412 events; the loaders keep magnitude 5.5 and above. `ecoli.arff` has 336
proteins, 7 features and 8 localization sites.

## Earthquakes 2023 (USGS)

No account or API key needed:

```bash
uv run python -m sc4020.weiyew.quake.usgs                       # 2023, magnitude 4.5+
uv run python -m sc4020.weiyew.quake.usgs --start 2023-01-01 --end 2024-01-01 --min-magnitude 4.5
```

Saves `data/usgs_<start>_<end>_m<magnitude>.csv`. The USGS API refuses queries that match more
than 20,000 events; narrow the dates or raise the magnitude if that happens.

## HDB resale prices and price index (data.gov.sg)

No account or API key needed:

```bash
uv run python -m sc4020.weiyew.hdb.datagov               # both datasets
uv run python -m sc4020.weiyew.hdb.datagov resale        # one dataset
uv run python -m sc4020.weiyew.hdb.datagov price_index
```

Each run saves a dated copy, `data/resale_<YYYY-MM-DD>.csv` and `data/price_index_<YYYY-MM-DD>.csv`.
The analysis reads the latest one, so results stay fixed until you download again. The downloader
retries when data.gov.sg rate-limits it.

## Datasets used only by Ky's notebook

`notebooks/ky/clustering_hotspot_project.ipynb` is self-contained: its loaders download the
Ridgecrest 2019 earthquake sequence (USGS), July 2023 Chicago thefts (City of Chicago portal) and
the original UCI Ecoli table into this folder on first run. Run the notebook from
`notebooks/ky/` so the `../../data/` paths resolve.
